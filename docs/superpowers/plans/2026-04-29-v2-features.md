> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement v2.0 features: Source testing/local nodes, GUI node grouping, external latency tracking, and SNI-based single-port domain routing.

**Architecture:** 
1. Database Schema: Expand SQLite models via GORM auto-migration.
2. Backend API: Add `POST /api/v1/latency/report`, update Source/NodeGroup CRUD to support relation tables (`group_replacements`, `group_routings`), implement SNI TLS proxy.
3. Frontend: Refactor `Groups.vue` and `Sources.vue` for GUI lists, add ECharts to `Traffic.vue`, add token reset in `Settings.vue`.

**Tech Stack:** Go 1.26, Gin, GORM (SQLite), Vue3, Pinia, TailwindCSS, ECharts.

```go
// backend/internal/service/proxy/sni_proxy.go
package proxy

import (
	"bytes"
	"errors"
)

// Minimal SNI extractor for TLS Client Hello
func extractSNI(data []byte) (string, error) {
	if len(data) < 43 || data[0] != 0x16 || data[5] != 0x01 {
		return "", errors.New("not a TLS ClientHello")
	}

	// This is a simplified extraction looking for the SNI extension bytes
	// In production, we use a robust parser. For this task, locating the specific 
	// extension type 0x00 0x00 is needed.
	idx := bytes.Index(data, []byte{0x00, 0x00})
	if idx == -1 || idx+5 > len(data) {
		return "", errors.New("SNI not found")
	}

	// Parse length and string (simplified for the test payload structure)
	sniLen := int(data[idx+4])
	if idx+5+sniLen > len(data) {
		return "", errors.New("SNI bounds error")
	}
	
	sni := string(data[idx+5 : idx+5+sniLen])
	return sni, nil
}
```
